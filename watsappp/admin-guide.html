Admin & Installation Guide

Introduction

Welcome to the WhatsApp Direct admin guide. This application is a static web app, which means it does not require a traditional backend server (like Node.js, PHP, or Python). All logic runs directly in the user's browser.

This makes hosting simple, cheap, and infinitely scalable. This guide will walk you through deploying the app and configuring its features.

Section 1: Installation & Deployment

To get the app online, you just need a place to host the static files (`.html`, `.css`, `.js`, etc.).

Steps:

  1. Download Files: Make sure you have all the application files in a single folder on your computer.
  2. Choose a Hosting Provider: Select a static web hosting provider. Excellent, easy-to-use options include:
    • Vercel
    • Netlify
    • Firebase Hosting
    • GitHub Pages
    • Cloudflare Pages
  3. Deploy the App: Follow your chosen provider's instructions. Most modern providers allow you to simply drag-and-drop your project folder to deploy it instantly. Alternatively, you can connect a GitHub repository for automatic deployments.

Once deployed, your app will be live on the internet! Now, you can configure the optional services below.

Section 2: Configuration

All configuration is done in the index.tsx file. Open this file and locate the configuration objects at the top.

Important: After making any changes to index.tsx, you will need to re-deploy or upload the updated file to your hosting provider.

1. Firebase Configuration

This is for connecting Google Analytics to track anonymous usage statistics.

const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_AUTH_DOMAIN",
  projectId: "YOUR_PROJECT_ID",
  // ... and other keys
};

How to get your Firebase config:

  1. Go to the Firebase Console and create a new project.
  2. In your project dashboard, click the "Web" icon (</>) to register a new web app.
  3. Give your app a nickname and click "Register app".
  4. Firebase will display the firebaseConfig object. Copy this entire object and paste it into index.tsx, replacing the placeholder values.

2. OneSignal Configuration

This is for enabling optional push notifications.

const oneSignalAppId = "YOUR_ONESIGNAL_APP_ID";

How to get your OneSignal App ID:

  1. Sign up at OneSignal and create a new App/Project.
  2. Choose "Web" as your platform.
  3. Follow the setup steps. In your OneSignal dashboard, go to Settings → Keys & IDs.
  4. You will find your OneSignal App ID here. Copy it and paste it as the value for oneSignalAppId.

3. AdSense Configuration

This section controls all monetization features.

const adsenseConfig = {
    ad_client_id: "ca-pub-xxxxxxxxxxxxxxxx",
    enable_ads: true,
    show_header_banner: true,
    header_banner_ad_slot: "YOUR_HEADER_AD_SLOT_ID",
    // ... and other settings
};

How to configure AdSense:

  • ad_client_id: This is your unique publisher ID from Google AdSense. You can find it in your AdSense account under Account → Settings → Account information. It looks like ca-pub-1234567890123456.
  • enable_ads: Set this to false to disable all ads across the app.
  • show_..._ad: These are switches to enable or disable specific ad placements (header, footer, interstitial).
  • ..._ad_slot: For each ad placement you enable, you must create a corresponding ad unit in your AdSense account (under Ads → By ad unit). After creating an ad unit, AdSense will give you a code snippet containing an ad slot ID (a string of numbers). Copy that ID and paste it here.
